Publish a theme

Public GitHub repositoryCurated listing

Publish the theme in its own public GitHub repository, make sure it installs with Omarchy's official command, then propose that repository for the curated registry.

Before submitting

  • A root colors.toml defines a complete, valid Omarchy palette.
  • At least one usable image lives under backgrounds/.
  • A root preview.png, .jpg, or .webp shows the desktop clearly.
  • The README includes installation, screenshots, credits, and any asset restrictions.
  • A license file clearly states how the theme and included assets may be used.
  • omarchy theme install <repository-url> succeeds on current Omarchy.

Submit the repository

The automated theme submission workflow will be implemented after the catalog and browsing experience are settled. For now, open an issue with the repository URL, theme name, author, short description, and tested Omarchy version.

What curation means

The marketplace checks repository structure and compatibility without executing source code. Listing is not a security review, endorsement, or guarantee that future upstream commits remain unchanged.
