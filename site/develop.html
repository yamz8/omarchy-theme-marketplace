Theme contract

Develop a theme

Git repositoryStatic assetsNo manifest

An Omarchy community theme is a public Git repository shaped for omarchy theme install. It uses the native theme repository format: a root palette, wallpapers, and optional supported assets.

Repository structure

omarchy-example-theme/
├── colors.toml       # required palette
├── preview.png       # recommended marketplace preview
├── backgrounds/      # one or more wallpapers
├── icons.theme       # optional icon theme name
├── keyboard.rgb      # optional keyboard palette
├── shell.lock.toml   # optional shell palette
├── README.md
└── LICENSE

Keep colors.toml at the repository root and images directly inside backgrounds/. Omarchy derives supported application colors from the palette and copies supported assets into the installed theme directory.

Define the palette

mode = "dark"

accent = "#7aa2f7"
background = "#1a1b26"
foreground = "#a9b1d6"

red = "#f7768e"
yellow = "#e0af68"
green = "#9ece6a"
cyan = "#449dab"
blue = "#7aa2f7"
magenta = "#ad8ee6"

Use six-digit hexadecimal colors and set mode to dark or light. Current built-in themes also define selection, muted, background variants, foreground variants, orange, brown, and bright ANSI colors for a complete result.

Repository naming

Use omarchy-<name>-theme. Omarchy removes the omarchy- prefix and -theme suffix to create the installed slug. For example, omarchy-giants-theme becomes giants.

Remote install behavior

Do not rely on root Lua files, symlinks, or pre-generated alacritty.toml, foot.ini, ghostty.conf, kitty.conf, or vscode.json. Remote theme installation filters those files; Omarchy generates supported application configuration from colors.toml.

Test the published repository

Install from GitHub
$ omarchy theme install https://github.com/you/omarchy-example-theme

The example installs under ~/.config/omarchy/themes/example. Verify a clean second install, terminals, Hyprland, Waybar, notifications, editors, icons, wallpapers, dark/light mode, selections, muted states, and readable contrast before publishing.
