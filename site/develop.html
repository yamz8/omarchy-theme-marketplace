Theme contract

Develop a theme

Git repositoryStatic assetsNo manifest

An Omarchy community theme is a public Git repository shaped for omarchy theme install. It is not a site skin and it does not use the plugin manifest format.

Repository structure

omarchy-example-theme/
├── colors.toml       # required palette
├── preview.png       # recommended marketplace preview
├── backgrounds/      # one or more wallpapers
├── icons.theme       # optional icon theme name
├── README.md
└── LICENSE

Keep colors.toml at the repository root. Omarchy derives supported application colors from this palette and copies the theme's supported assets into its local theme directory.

Repository naming

Use omarchy-<name>-theme. Omarchy removes the omarchy- prefix and -theme suffix to create the installed slug. For example, omarchy-giants-theme becomes giants.

Test locally

Install from GitHub
$ omarchy theme install https://github.com/you/omarchy-example-theme

Verify terminals, Hyprland, Waybar, notifications, editors, icons, backgrounds, dark/light mode, and readable contrast before publishing.
